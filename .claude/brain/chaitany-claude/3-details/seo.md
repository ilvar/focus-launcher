# Tier 3 · Being found in search

Goal, in the owner's words: when someone searches for minimalist apps, Focus should at least show.
**Never promise a ranking.** Expectation given to him: brand queries within days of indexing,
long-tail ("text only launcher no icons") in weeks, the head term "minimalist launcher" in months
and only with other sites linking in.

## Audit before the work (2026-09-19)
No robots.txt, no sitemap, **no inbound link from anywhere**, and the word "minimalist" appeared
on the page **zero** times.

## Done
- `<title>`: "Reclaim your time — Focus, a minimalist launcher for Android". His headline stays
  the visible `<h1>`; the small label above it ("Minimalist launcher for Android") is now *inside*
  the `<h1>` as `.eyebrow`, so the heading carries the phrase without changing the look.
- Description, `meta robots` (index, follow, large image preview), canonical, OG/Twitter tags,
  1200×630 `og.png` rendered from `og.svg`.
- Section "What a minimalist launcher is, and what this one adds": uses the phrases people type
  (distraction-free, text-based launcher, app blocker, screen time, dumb phone) and names
  Olauncher, Niagara, Before Launcher and minimalist phone **neutrally** (no claims about what
  they lack or cost). "minimalist" ≈ 12 times in ~1,900 visible words: present, not stuffed.
- FAQ: 10 questions incl. free?, which phones, vs Digital Wellbeing, APK safety, source code.
- JSON-LD generated by `site/build.sh` **from the page itself**: `MobileApplication` (free, Android
  8.0+, version, size, download URL, feature list; **no ratings**, there are none) + `FAQPage`.
- `sitemap.xml` (lastmod = build date), domain-root `robots.txt` via the nginx snippet.
- IndexNow: key in `site/src/indexnow-key.txt` (public by design), key file published under
  `/focusapp/`, `deploy.sh` pings `api.indexnow.org` after every deploy (got 202, later 200).
  Covers Bing, Yandex, Seznam, Naver. **Google does not take part.**
- First inbound links: the GitHub repo's homepage field and README → site; site → repo.

## Not done
1. **Google Search Console** (needs the owner's Google account): add URL-prefix property
   `https://how2me.me/focusapp/` → HTML-file method → drop `google….html` into `site/src/` (the
   build publishes it) → `site/deploy.sh` → Verify → submit `sitemap.xml` → request indexing.
   Bing Webmaster Tools can import from it.
2. A link to `/focusapp/` from the how2me.me homepage (his other site; offered, not edited).
3. Mentions elsewhere: AlternativeTo, r/androidapps, r/digitalminimalism, Product Hunt. Posting
   on his behalf needs his accounts and explicit permission.

## Guardrails
No doorway pages, no fake reviews or `aggregateRating`, no hidden text, no claims about
competitors. Page speed is already excellent (no JS, no fonts, ~35 KB): do not add trackers or
analytics; "nothing third-party" is part of the pitch.
